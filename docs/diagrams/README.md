# Diagrams

These standalone Archify HTML files work offline and include dark/light themes
plus PNG, JPEG, WebP, and SVG export:

- [`shelllane-architecture.html`](shelllane-architecture.html)
- [`ssh-container-sequence.html`](ssh-container-sequence.html)

GitHub serves HTML as source. Clone the repository and open the file in a
browser for the interactive view:

```bash
xdg-open docs/diagrams/shelllane-architecture.html
```

Maintainable, schema-validated JSON sources are under [`source/`](source/).
